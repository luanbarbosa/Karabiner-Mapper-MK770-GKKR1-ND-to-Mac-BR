MK-770 (Nordic) → Mac key mapper

Makes every key on the Cooler Master MK-770 type what its keycap says on your Mac. Everything runs locally in this page.

1 · Setup

  1. Open Karabiner-Elements → Devices, find the MK-770 and note its Vendor ID and Product ID. Entering them makes the rules apply only to this keyboard, so the MacBook's own keys stay untouched.
  2. Keep the MK-770 plugged in but do the recording (step 3) on the MacBook's built-in keyboard.

2 · MK-770 keys

Click a key to edit it. Green = has a mapping. Top-left = Shift legend, bottom-left = base, bottom-right = AltGr.

3 · Map the selected key

4 · Karabiner JSON

  1. Save it as ~/.config/karabiner/assets/complex_modifications/mk770-nordic-to-mac.json
  2. Karabiner-Elements → Complex Modifications → Add predefined rule → enable the rules.
